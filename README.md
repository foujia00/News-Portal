# 📰 News Portal – Online News Website

A responsive and user-friendly news portal website designed to present the latest news and information across different categories, including National, Politics, Sports, Education, and Entertainment.

## 🌐 Live Website

[Visit News Portal](https://foujia00.github.io/News-Portal/)

## 📌 About The Project

**News Portal** is a multi-page frontend website developed to provide an organized platform for browsing news and information.

The website features a clean layout, categorized news sections, a breaking news ticker, reporter information, and a contact page.

It is designed to provide visitors with an accessible and convenient news-browsing experience.

## ✨ Features

- **Home Page:** Displays lead news, latest news, and categorized news sections.
- **Breaking News:** Shows important news headlines using a Bootstrap carousel.
- **News Categories:** Includes National, Politics, Sports, Education, and Entertainment.
- **About Page:** Provides information about the news portal, editorial speech, and policies.
- **Author Page:** Displays information about senior and general reporters.
- **Category Page:** Organizes news articles by category.
- **Contact Page:** Provides a contact form and contact information.
- **Reporter Login:** Includes a login interface for reporters.
- **Responsive Navigation:** Easy navigation between different website pages.
- **Social Media Links:** Includes social media icons and links.
